# Lesson Plans for Game Development Course

## Lesson 1: Introduction to Godot and Drawing Basics

### Learning Objective

Understand the Godot interface and learn to draw basic shapes using GDScript.

### Success Criteria

- I can identify the main parts of the Godot interface
- I can use and interpret the co-ordinates system in Godot
- I can write a script to draw circles and rectangles on the screen

### Resources

- Godot Engine Download: [Download Godot Engine](https://godotengine.org/download)
- Task 1 Sample Code
- [Godot Editor Interface Guide] (godot-editor-interface.md)
